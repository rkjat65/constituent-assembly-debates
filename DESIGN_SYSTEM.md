# Constituent Assembly Debates — Locked Visual System

This document records the approved master visual direction. New pages should inherit this system rather than reinterpret it.

## 1. Master composition

Desktop debate pages use the same hierarchy:

1. persistent left navigation rail;
2. top session header with back navigation, source citation, share and theme control;
3. session title + date / time / venue metadata line;
4. compact metadata chips;
5. three-column reading area:
   - personality portrait card;
   - primary excerpt + concise summary;
   - annotations / context / linked records;
6. structured visual transcript beneath the reading area;
7. transcript/read-along utility rail;
8. source and project attribution footer.

Do not introduce a new dashboard composition for an individual sitting unless explicitly approved.

## 2. Light theme

The light theme is the canonical appearance.

- Background: warm archival cream / parchment, not pure white.
- Cards: slightly lighter paper surfaces with fine warm-grey / gold borders.
- Primary ink: near-black warm neutral.
- Saffron: interaction and emphasis.
- Green: context, links and secondary semantic emphasis.
- Ashoka blue: sparing civic accent only.
- Gold / sepia: archival illustration and decorative line work.

Tricolour references must remain restrained. The site should feel constitutional and archival, not like a flag-themed promotional page.

## 3. Typography

- Editorial / historical voice: serif typography.
- Strong hierarchy; avoid dense small text.
- Quotes receive significantly larger type than summaries.
- Metadata is compact but must remain legible.
- No decorative display font that competes with the content.

## 4. Personality portraits

**Generic headshots, profile placeholders and stock imagery are not acceptable.**

Every major personality must have a dedicated custom illustration in the same family:

- sepia / engraved / hand-rendered archival treatment;
- parchment ground;
- restrained tricolour brush or line accent where compositionally useful;
- no cartoon exaggeration;
- recognisable likeness;
- no modern photographic background;
- consistent crop, edge treatment and tonal range across personalities.

If a historic source image is used as visual reference, its source and licensing must be documented in `THIRD_PARTY_NOTICES.md`.

## 5. Archival motifs

Allowed motifs include:

- Constitution / Assembly building line art;
- Ashoka Chakra;
- elephant motifs associated with the original Constitution artwork;
- fine manuscript / paper textures;
- understated period-document ornament.

Use motifs as framing devices, not content substitutes.

## 6. Debate text

The interface is intentionally not a transcript wall.

Preferred units:

- one strong excerpt;
- one concise editorial summary;
- structured intervention rows;
- contextual callouts;
- speaker / theme / document / provision links.

The complete record should remain one click away at the official source.

## 7. Accuracy rules

Visual polish never overrides historical accuracy.

- Never reuse a famous quotation on the wrong date because it looks better.
- Never invent timestamps for interventions.
- Never imply audio exists unless a verified recording exists.
- Never present an editorial paraphrase with quotation marks.
- Never hide source provenance.

## 8. Responsive behaviour

Desktop fidelity to the approved master composition has priority. On narrow screens, content may stack while preserving the same hierarchy and visual tokens. Responsive adaptation is allowed; independent redesign is not.
