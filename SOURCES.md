# Sources and Editorial Provenance

## Canonical source

For Constituent Assembly debate text, dates and official records, the canonical source for this project is the **Parliament Digital Library (PDL), Lok Sabha Secretariat**.

- Constituent Assembly Draft Making Debates collection: `https://eparlib.sansad.in/handle/123456789/760448`
- Official historical debates portal: `https://sansad.in/ls/debates/historical`
- 9 December 1946: `https://eparlib.sansad.in/handle/123456789/762978?view_type=browse`
- 10 December 1946: `https://eparlib.sansad.in/handle/123456789/762976?view_type=browse`

## Presentation layers

Every piece of content should belong to one of these provenance classes:

1. **Primary record** — verbatim excerpt or factual metadata traceable to the parliamentary record.
2. **Editorial summary** — concise explanation written for this website; never presented as a quotation.
3. **Theme / provision link** — an editorial classification connecting an intervention to a constitutional theme or provision.
4. **Visual asset** — a custom illustration used for orientation and storytelling; never represented as an archival photograph.

## Non-negotiable rules

- Do not invent intervention timestamps when the official record provides only the sitting start time.
- Do not represent a generated audio control as an archival recording unless an actual verified recording is linked.
- Do not silently modernise or alter a quotation.
- Keep quotations short in the interface; link users to the official record for full context.
- Preserve speaker, date, sitting and source metadata beside or immediately accessible from every excerpt.
- Clearly label editorial notes and summaries.
- If secondary sources are used to improve navigation or tagging, they must not override the parliamentary record.
