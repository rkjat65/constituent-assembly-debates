One visual language

Every public personality image belongs to the same generated editorial family.

The archive uses a consistent sepia-parchment portrait treatment with restrained tricolour accents. Archival photographs, stock images and substitute faces are not part of the public visual system. When a generated likeness has not yet been uploaded, the interface falls back to initials.
