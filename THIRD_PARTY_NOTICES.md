# Third-Party Notices and Attribution

This project uses primary parliamentary records as source material and custom illustrated personality assets for visual presentation.

## Parliamentary source material

The canonical debate records linked by this project are maintained by the **Parliament Digital Library / Lok Sabha Secretariat**.

- Collection: `https://eparlib.sansad.in/handle/123456789/760448`
- Historical debates entry point: `https://sansad.in/ls/debates/historical`

Parliament Digital Library states that items are protected by copyright, with all rights reserved unless otherwise indicated. This project therefore does **not** mirror the full PDFs or reproduce complete debate transcripts. It links to the official records and uses limited excerpts, factual metadata and independently authored summaries for navigation and interpretation.

This website is an independent project and is not affiliated with, endorsed by, or an official publication of Parliament of India.
